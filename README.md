# AlgoGo

![Go Version](https://img.shields.io/badge/Go-1.20%2B-green.svg)
![License](https://img.shields.io/badge/License-AGPL%20v3-green.svg)

**AlgoGo** - это консольное приложение на Go для генерации массивов и тестирования различных алгоритмов сортировки.

Проект создается в первую очередь в образовательных целях для изучения алгоритмов. За основу взят
ресурс [AlgoLab](http://algolab.valemak.com)

> **Примечание:** Проект разрабатывается на Go версии `1.27.1`, но не использует специфичных экспериментальных фич,
> поэтому должен успешно собираться на версиях `1.20` и выше.

---

## Возможности

- **Генерация массивов:**
    - Настройка размера массива;
    - Задание диапазона случайных чисел через нижнюю и верхнюю границы;
- **Направление сортировки:** Поддержка сортировки по возрастанию и по убыванию;
- **Режим отладки:** Наглядный вывод массива в консоль до и после сортировки.

## Аргументы командной строки

| Флаг     | Тип    | Описание                                 | Допустимые значения                         | По умолчанию |
|----------|--------|------------------------------------------|---------------------------------------------|--------------|
| -algo    | string | Алгоритм сортировки                      | stupid, bubble                              | stupid       |
| -order   | string | Порядок сортировки                       | asc (по возрастанию) или desc (по убыванию) | asc          |
| -size    | int    | Размер массива                           | Целое число > 0                             | 100          |
| -min     | int    | Нижняя граница генерации (включительно)  | от -2<sup>31</sup> до 2<sup>31</sup> - 1    | 0            |
| -max     | int    | Верхняя граница генерации (включительно) | от -2<sup>31</sup> до 2<sup>31</sup> - 1    | 10           |
| -verbose | bool   | Вывод массива до и после сортировки      | true/false                                  | false        |

## Сборка/Запуск проекта
### Склонируйте и перейдите в репозиторий:
```bash
git clone https://github.com/Shogun-Sun/algogo.git && cd algogo 
```
### Запустить проект:
```bash
make run
```

### Запустить Бенчмарк-тест:
```bash
make bench-test
```

> **Примечание:** При первом запуске команда автоматически скачает утилиту анализа производительности benchstat в локальную директорию проекта `.bin/`.

### Очистить проект:
```bash
make clean
```

### Собрать проект:
```bash
make build
```

> **Примечание:** Собранный проект помещается в ./build/algogo
